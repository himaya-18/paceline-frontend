# Paceline — Running & Performance

A responsive frontend website for Paceline, a modern running and performance retail brand.

## About the Project

Paceline is a responsive e-commerce-style website focused on running, trail running, apparel and accessories.

This project was developed as part of the DCS Web Cluster Frontend Task.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* Vercel

## Features

* Responsive design for desktop, tablet and mobile
* Product category sections
* Product ratings and stock urgency
* Product filtering
* Back-to-top button and cookie banner
* Gait booking form
* Dark mode
* Currency Switcher
* Wishlist interaction
* Cart interaction
* Newsletter interaction
* Responsive navigation
* About page
* Responsive footer
* Lazy loading for applicable images

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/himaya-18/paceline-frontend.git
```

2. Open the project folder in VS Code.

3. Open `index.html` in a browser or use the VS Code Live Server extension.

## Deployment

The website is deployed using Vercel.
